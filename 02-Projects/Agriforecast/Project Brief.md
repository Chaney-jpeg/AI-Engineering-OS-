# Agriforecast — Project Brief

## Overview

Agriforecast is a weather-driven agricultural decision-support
web application designed for smallholder farmers in Kenya.

It aims to help farmers make more informed agricultural
decisions using weather information and agricultural knowledge.

## Target Users

Primary users:
- Smallholder farmers in Kenya.

Potential secondary users:
- Agricultural extension officers.
- Agricultural researchers.
- Other agricultural stakeholders.

## Core Problems

Farmers need accessible information to help them understand:

1. Which crops may be suitable for planting.
2. Which crop diseases or agricultural risks to watch for.
3. How seasonal weather conditions may affect livestock.

## Core Features

### 1. Crop Planning
Use weather information and relevant agricultural knowledge
to help users evaluate potential crops and planting periods.

### 2. Crop Disease Risk
Identify potential weather-related crop disease risks.

Clearly distinguish potential risks from confirmed
disease diagnoses.

### 3. Livestock Seasonal Outlook
Explain how seasonal weather conditions may affect livestock,
including potential heat, water, and feed-related challenges.

### 4. Weather Information
Present relevant weather forecasts in an understandable format.

### 5. Agricultural Recommendations
Translate weather information into practical,
understandable recommendations.

## Initial Scope

- Begin with one county in Kenya.
- Focus on smallholder farmers.
- Use English as the initial application language.
- Build a web application.
- Expand the geographic scope only after validating the MVP.

## Important Limitations

Agriforecast must not present estimates as verified facts.

Every recommendation should distinguish between:
- Weather forecast information.
- Evidence-based agricultural guidance.
- Model-generated estimates.
- Confirmed observations, where available.

Recommendations must communicate uncertainty
and avoid guaranteeing agricultural outcomes.

## MVP Success Criteria

The MVP should demonstrate that a user can:

1. Access relevant weather information.
2. Explore potential crop choices.
3. Understand potential weather-related crop risks.
4. View a seasonal livestock outlook.
5. Understand the reasoning and uncertainty behind recommendations.

## Open Questions

- Which Kenyan county should the MVP support first?
- Which weather data provider will be used?
- Which agricultural information sources will be integrated?
- How will recommendations be generated and validated?
- How will users access the application?
