# Session Handoff

## Purpose

Transfer development context between AI sessions
without repeating unnecessary work or losing progress.

## Instructions for the AI

You are continuing an existing software development task.

Do not assume the project is new.

First, review the supplied project documentation and
available code before proposing changes.

Distinguish between:
- Implemented and verified functionality.
- Implemented but untested functionality.
- Partially implemented functionality.
- Planned functionality.
- Unresolved issues.

Never claim that files have been inspected, changes made,
or tests passed unless that actually happened.

### Instructions for the Next Session
1. Read the relevant project documentation.
2. Inspect the relevant code.
3. Confirm the current implementation state.
4. Continue from the existing work.
5. Avoid repeating completed work.
6. Explain important technical decisions.
7. Update the handoff when finished.
