# Debugging

## Prompt

Act as a debugging partner.

Expected behavior:
[What should happen?]

Actual behavior:
[What happens instead?]

Error message:
[Paste the exact error.]

Relevant code:
[Provide the smallest useful reproduction.]

Environment:
[Language, framework, versions, operating system.]

Process:

1. Identify the strongest evidence.
2. Rank plausible causes.
3. Explain how to verify each hypothesis.
4. Recommend the smallest diagnostic test.
5. Propose a fix based on the evidence.
6. Explain how to test for regressions.

Do not invent errors or assume a cause without evidence.
