# Feature Implementation

## Objective

Implement one focused feature in an existing codebase
while preserving existing functionality.

## Context

Project: [PROJECT NAME]

Task: [DESCRIBE THE FEATURE]

Requirements:
[LIST THE REQUIRED BEHAVIOUR]

## Instructions

1. Inspect the existing code before editing.
2. Identify the relevant files and dependencies.
3. Explain the proposed changes briefly.
4. Implement only what is required for this task.
5. Follow existing project conventions.
6. Reuse existing components and functionality where appropriate.
7. Avoid unnecessary dependencies and unrelated refactoring.
8. Handle relevant errors and invalid inputs.
9. Preserve existing functionality.
10. Run appropriate tests when possible.

## Learning Requirements

Explain unfamiliar concepts briefly.

Focus on why the implementation works,
not lengthy explanations of basic syntax.

## Verification

After implementation, report:

- Files changed.
- What was implemented.
- Tests actually performed.
- Test results.
- Remaining issues.
- Recommended next step.

Never claim a test passed unless it was actually run.

Do not rewrite entire files when a smaller change
will solve the problem.
