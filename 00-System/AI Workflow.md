# AI Development Workflow

## Before Starting a Task

1. Identify the project.
2. Read its project brief.
3. Identify the current objective.
4. Select the appropriate prompt.
5. Provide only the relevant context.

## During Development

1. Understand the existing implementation.
2. Plan the changes.
3. Review the proposed approach.
4. Implement focused changes.
5. Run appropriate tests.

## After Development

1. Review the changes.
2. Record actual test results.
3. Document unresolved issues.
4. Update the project status.
5. Save a session handoff when necessary.

## Important Rules

Do not assume a proposed change was implemented.

Do not assume a test passed without evidence.

Do not rewrite working components unnecessarily.

Keep project documentation consistent with
the verified state of the codebase.

## Main Principle

Every significant AI-assisted development session
should leave the project easier to understand
and easier to continue working on.
