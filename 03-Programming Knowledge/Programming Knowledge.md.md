# Programming Knowledge

My personal reference for programming concepts,
software development, and computer science.

The objective is to understand how software works,
not simply memorize syntax or copy generated code.

## Learning Principles

When documenting a new concept, include:

1. Definition
2. Problem it solves
3. How it works
4. Code example
5. Common mistakes
6. Practical application
7. Exercises or questions

## Knowledge Areas

### Programming Fundamentals
Variables, data types, operators, conditions, loops,
functions, scope, error handling, and debugging.

### Data Structures and Algorithms
Arrays, linked lists, stacks, queues, hash tables,
trees, graphs, searching, sorting, recursion, and Big O.

### Python
Syntax, collections, functions, modules, OOP,
exceptions, file handling, testing, and virtual environments.

### Java
Syntax, object-oriented programming, collections,
exceptions, generics, and application structure.

### JavaScript and React
JavaScript fundamentals, asynchronous programming,
components, props, state, hooks, routing, and API integration.

### Django and APIs
Django models, views, serializers, URL routing,
Django REST Framework, authentication, permissions,
validation, and API testing.

### Databases and SQL
Relational modelling, SQL queries, joins, indexes,
constraints, transactions, and database optimization.

### Software Engineering
SOLID, DRY, KISS, YAGNI, Git, testing, architecture,
design patterns, requirements, and deployment.
